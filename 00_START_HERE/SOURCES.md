# SOURCES

Built 2026-10-30. Questions were harvested (questions only, no answers) from the public GitHub repositories below, cleaned, translated to English where needed, de-duplicated and re-organised by topic. A question can be traced back to its source repo/path in `_meta/questions.jsonl`.

**Licence note.** Many of these repos carry no licence or a restrictive one (GPL etc.). This corpus is for **private study / personal RAG use**. Do not redistribute it publicly without re-checking each source's licence.

Notes-style repos (JavaGuide, CS-Notes, wdndev/llm_interview_note, gyoogle, system-design guides, …) are not question lists; questions from them were *derived* by Claude from their topic structure. Questions marked generated were written by Claude to fill coverage gaps.
